✍️ Answer-writing tips for RTU

  • Diagrams get marks. The paper itself says "Schematic diagrams must be shown wherever necessary." Every 4- and 10-mark answer should have one. Use a pencil and label everything.
  • Start each answer with a one-line definition in a box, then use headings and bullets. Examiners skim.
  • Write formulas in a separate line. Comparison questions → always a table.
  • For "design" questions, give a layer table (layer / neurons / activation) + loss + optimiser.
  • For numericals, write the given data, the formula, the substitution and the answer, then a "check" line.
  • Finish 10-mark answers with "Applications" and a 1-line conclusion.
