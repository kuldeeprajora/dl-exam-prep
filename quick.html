Unit 1 — Deep Network BasicsMost scoring for Part A/B · backprop asked in all 3 papers

1. Backpropagation 🔥 MUST ×3

Def: An algorithm that computes the gradient of the loss w.r.t. every weight using the chain rule, from output to input, and then updates the weights by gradient descent.
  • Steps: ① initialise random weights ② forward pass (net = Σwx + b, o = f(net)) ③ compute loss E = ½Σ(t − o)² ④ backward pass: find δ for each neuron ⑤ update w ← w + η·δ·x ⑥ repeat for epochs.
  • Formulas: output δₖ = (tₖ − oₖ)·f′(netₖ); hidden δⱼ = f′(netⱼ)·Σ wⱼₖδₖ; Δw = η·δ·input. For sigmoid, f′ = o(1 − o).
  • Variants: batch GD, SGD, mini-batch, momentum, Adam, BPTT (for RNNs).
  • Problems: vanishing/exploding gradients, local minima, needs labelled data, sensitive to the learning rate.
Yaad rakho: galti output pe dikhi → peeche jaake har weight ko uska "hissa" batao → har weight thoda sudhro. Jaise coach haar ke baad har player ko feedback deta hai.

2. Curse of Dimensionality 🔥 MUST ×2

Def: As the number of features (dimensions) grows, the space grows exponentially, so the data becomes sparse and models need far more data to generalise (term by Bellman).
  • Example: 10 bins per feature → 1D = 10 cells, 2D = 100, 3D = 1000, d dims = 10ᵈ.
  • Problems: data sparsity, distances lose meaning (k-NN fails), overfitting, high computation, Hughes phenomenon.
  • DL solutions: autoencoders (bottleneck), representation learning, CNN parameter sharing + pooling, embeddings, dropout/L1/L2, data augmentation, PCA.
Yaad rakho: features badhe → space bada → data "khaali-khaali". Solution = compress karo (autoencoder/PCA) + regularise.

4. Multilayer Perceptron (MLP) / 3-layer NN for binary classification 🔥 MUST

Def: A fully-connected feed-forward network with an input layer, ≥1 hidden layer with non-linear activation, and an output layer, trained with backpropagation.
  • Design: Input = n features → Hidden = ReLU neurons → Output = 1 neuron with sigmoid (probability).
  • Loss: binary cross-entropy. Optimiser: SGD/Adam. Decision: ŷ ≥ 0.5 → class 1.
  • Working: forward pass → loss → backprop → update → repeat over epochs → evaluate with accuracy/precision/recall.
  • Can learn non-linear boundaries (e.g. XOR), which a single perceptron cannot.
Yaad rakho: Input = data andar, Hidden = sochne waala dimaag (ReLU), Output = sigmoid se 0–1 probability. Pass/Fail predict karna.

5. Deep Feed-forward Network ⭐ HIGH

Def: A network where information flows only forward (input → hidden → output) with no feedback loops; it approximates y = f*(x) as a chain f(x) = f³(f²(f¹(x))).
  • Depth = number of layers in the chain; hidden layers are not directly seen in the training data.
  • A non-linear activation is required; otherwise all layers collapse into one linear layer.
  • Universal approximation theorem: one hidden layer with enough neurons can approximate any continuous function.
  • XOR cannot be solved by one line, but one hidden layer solves it.
Yaad rakho: factory ki assembly line, maal sirf aage jaata hai, kabhi peeche nahi.

6. Perceptron ⭐ HIGH

Def: The simplest neuron (Rosenblatt, 1958): y = step(Σwᵢxᵢ + b). Learning rule: w ← w + η(t − y)x.
  • Converges if the data is linearly separable (AND, OR). Fails for XOR (Minsky & Papert), which is why MLPs were needed.
Yaad rakho: inputs × importance → jodo → threshold paar = 1, warna 0.

7. Maximum Likelihood Estimation (MLE) ✔ MED (never asked, so it's "due")

Def: Choose the parameters θ that make the observed data most probable: θML = argmax Σ log p(xᵢ; θ).
  • We use log because a product of many small probabilities underflows; a sum is easier.
  • Coin example: 7 heads in 10 tosses → p̂ = 0.7.
  • In DL: minimising cross-entropy = maximising likelihood (NLL). MSE = MLE under Gaussian noise.
Yaad rakho: "kaunsa parameter hota toh yeh data aane ka chance sabse zyada?"

8. Building an ML algorithm + Learning algorithm ✔ MED

  • 4 components: Dataset + Model + Cost function + Optimisation procedure.
  • Pipeline: Problem definition → Data collection/preprocessing → Model selection → Training → Evaluation → Deployment.
  • Learning (Mitchell): a program learns from experience E for task T with performance P if P on T improves with E. E.g. spam filter.
Yaad rakho: recipe: data = saamaan, model = bartan, loss = swaad check, optimiser = aanch.

Unit 2 — Deep Learning ArchitecturesHighest weightage: up to 32 marks in a paper · 2 Part C questions possible

9. Unsupervised training of neural networks 🔥 MUST ×3

Def: Training a network on unlabelled data (x only) so that it learns hidden structure or a useful representation, using an objective like reconstruction error or energy minimisation instead of labels.
  • Approaches: ① Autoencoders (minimise ‖x − x̂‖²) ② RBMs / Deep Belief Nets (contrastive divergence) ③ Self-Organising Maps / competitive learning (clustering) ④ Self-supervised learning (predict a masked part).
  • Greedy layer-wise pre-training: train layer 1 (RBM/AE) on x → freeze → train layer 2 on layer-1 output → stack → fine-tune with a few labels.
  • Example: MNIST digits without labels → autoencoder 784→64→784 → the 64-number codes of similar digits cluster together → k-means groups the digits.
  • Supervised vs unsupervised: labelled (x, y) vs only x; predict y vs find structure; loss vs label vs reconstruction/energy loss; e.g. classification vs clustering.
Yaad rakho: bina teacher ke seekhna: khud se data ko compress karke wapas banao, jo pattern bache wahi seekh gaya.

10. Restricted Boltzmann Machine (RBM) 🔥 MUST ×3

Def: A generative, energy-based, unsupervised neural network with two layers, visible v and hidden h, connected as a bipartite graph: there are no visible–visible or hidden–hidden connections ("restricted").
  • Energy: E(v, h) = −aᵀv − bᵀh − vᵀWh, and P(v, h) ∝ e−E. Low energy = likely configuration.
  • P(hⱼ = 1 | v) = σ(bⱼ + Σᵢ vᵢwᵢⱼ), P(vᵢ = 1 | h) = σ(aᵢ + Σⱼ wᵢⱼhⱼ). Symmetric weights W.
  • Training: Contrastive Divergence (CD-1): v → sample h → reconstruct v′ → h′; ΔW = η(vhᵀ − v′h′ᵀ).
  • Uses: feature learning, dimensionality reduction, collaborative filtering (Netflix), pre-training; stacked RBMs form a Deep Belief Network.
Yaad rakho: do layers, beech mein connections, apni layer mein koi dosti nahi. Data ko "energy" se samajhta hai.

13. Representation Learning ⭐ HIGH

Def: Learning useful features (representations) directly from raw data instead of hand-engineering them, so DL automates feature engineering.
  • Hierarchy: image: pixels → edges → shapes/textures → parts (eye, nose) → object (face). Speech: waveform → frequencies → phonemes → words.
  • Types: supervised (CNN features), unsupervised (autoencoders, RBMs), self-supervised, transfer learning (ImageNet features reused).
  • Benefits: better generalisation, less manual work, reusable features, handles high-dimensional data.
Yaad rakho: pehli layer lines dekhti hai, agli shapes, phir aankh-naak, last mein poora chehra.

14. Width and Depth of Neural Networks ⭐ HIGH

  • Width = neurons per layer; Depth = number of layers.
  • Wide and shallow: can approximate (universal approximation) but needs very many neurons and memorises easily.
  • Deep and narrow: learns hierarchical features with far fewer parameters, so it generalises better; but it's harder to train (vanishing gradient, needs ReLU/BN/ResNet skips).
  • In practice, depth gives more benefit than width (e.g. VGG, ResNet-152).
Yaad rakho: width = ek floor pe kitne log, depth = kitni manzilein. Zyada manzilein = zyada level ki samajh.

15. Deep Learning Applications ✔ MED

  • Vision: face unlock, medical X-ray/MRI diagnosis, self-driving cars, OCR. NLP: translation, chatbots, sentiment. Speech: Alexa, Siri, voice typing. Others: recommendations (Netflix), fraud detection, drug discovery, game playing (AlphaGo).

Unit 3 — Convolutional Neural NetworksPart C favourite: CNN architecture and AlexNet asked as 10-markers

16. CNN architecture, working & applications 🔥 MUST ×3

Def: A deep network for grid data (images) that uses convolution layers with learnable filters to automatically extract spatial features, followed by pooling and fully connected layers for prediction.
  • Input layer: image, e.g. 32×32×3 (RGB).
  • Convolution layer: filters (3×3, 5×5) slide over the image and compute dot products → feature maps (edges, textures). Hyper-parameters: number of filters, size, stride, padding. Output size = (n − f + 2p)/s + 1.
  • ReLU: adds non-linearity.
  • Pooling layer: max/average pooling (2×2) reduces size and gives translation invariance.
  • Flatten + fully connected layer: combines features. Softmax output gives class probabilities.
  • Training: backprop + SGD/Adam with cross-entropy loss.
  • CV applications: image classification, object detection (YOLO), segmentation (medical), face recognition, self-driving cars, OCR, satellite imagery.
Yaad rakho: Conv = magnifying glass jo photo pe ghoomta hai aur pattern dhoondhta hai; Pool = photo chhoti karo par important cheez rakho; FC = final faisla.

17. AlexNet vs ResNet 🔥 MUST ×2 (Part C)

AlexNet (2012), by Krizhevsky, Sutskever and Hinton, won ImageNet with a top-5 error of ~15.3% (vs 26% for the runner-up) and started the DL revolution. ResNet (2015), by He et al., introduced skip connections, trained 152 layers, and reached a top-5 error of ~3.57%, better than humans.
  • AlexNet architecture: input 227×227×3 → 5 conv layers (96@11×11 stride 4 → 256@5×5 → 384@3×3 → 384@3×3 → 256@3×3) with max-pooling → 3 FC layers (4096, 4096, 1000 softmax). ~60M parameters.
  • AlexNet's innovations: ReLU (fast training), dropout 0.5 in FC layers, data augmentation, overlapping max-pool, LRN, training on 2 GPUs.
  • ResNet idea: very deep plain nets got worse (degradation / vanishing gradient). A residual block learns F(x) and outputs y = F(x) + x, so the gradient flows directly through the shortcut.

18. Parameter Sharing 🔥 MUST ×2

Def: In a CNN, the same filter weights are used at every position of the input instead of separate weights for each location.
  • Purpose: ① huge reduction in parameters (a 5×5×3 filter = 75 weights, whatever the image size) ② the same feature (e.g. an edge) is detected anywhere → translation equivariance ③ less overfitting, less memory, faster training.
Yaad rakho: ek hi chashma poori photo pe, har jagah naya chashma nahi chahiye.

19. Regularisation in CNNs / Dropout 🔥 MUST ×2

Def: Techniques that reduce overfitting (good on training data, bad on test data) so the model generalises.
  • Dropout: during training, randomly switch off neurons with probability p (e.g. 0.5); no single neuron can be relied on, so neurons learn robust features. It acts like an ensemble of many thinner networks. At test time all neurons are used (scaled).
  • L2 / weight decay: add λΣw² to the loss → small weights. L1: λΣ|w| → sparse weights.
  • Data augmentation: flips, rotations, crops, colour changes → more data.
  • Batch normalisation, early stopping (stop when validation loss rises).
Yaad rakho: dropout = team ke kuch players ko randomly bench pe bithao, sab players mehnat seekhte hain, koi ek star pe depend nahi.

20. Motivation for CNNs ⭐ HIGH

  • Sparse interactions (local connectivity): each neuron sees only a small patch.
  • Parameter sharing: the same filter everywhere.
  • Equivariance to translation: an object shifts → its feature map shifts; pooling adds invariance.
  • FC nets on images have too many parameters (a 224×224×3 image means 150k inputs per neuron) and ignore spatial structure.

21. Layers & Filters (stride, padding, pooling) ⭐ HIGH

  • Filter/kernel: a small learnable weight matrix (3×3) that detects one pattern (vertical edge, colour blob…). The number of filters = the depth of the output.
  • Stride: step size of the slide (2 halves the size). Padding: zeros around the border ("same" keeps the size, "valid" means no padding).
  • Pooling: max (keeps the strongest) / average; no learnable parameters.
  • Layer sequence: Input → [Conv → ReLU → Pool] × N → Flatten → FC → Softmax.

Unit 4 — Sequence Modelling: RNN, LSTMLSTM / speech pipeline asked as Part C in both 2025 papers

22. Recurrent Neural Network (RNN) 🔥 MUST

Def: A neural network for sequential data whose hidden state carries memory from previous time steps: hₜ = tanh(Whhhₜ₋₁ + Wxhxₜ + b), yₜ = Whyhₜ. The same weights are shared across all time steps.
  • Types: one-to-many (image captioning), many-to-one (sentiment), many-to-many (translation, NER).
  • Implementing for sequence prediction: ① collect the series (e.g. daily temperature) ② normalise + make sliding windows (7 days → next day) ③ model: RNN/LSTM layer → Dense output ④ loss MSE, optimiser Adam, train with BPTT ⑤ validate (RMSE) → predict.
  • Problem: vanishing gradient → forgets long-term information, so LSTM/GRU are used.
Yaad rakho: kahaani padhte waqt pichhli line yaad rehti hai. RNN har step pe apne "notes" (hidden state) aage bhejta hai.

23. LSTM + RNN vs LSTM vs GRU 🔥 MUST Part C

Def: Long Short-Term Memory (Hochreiter & Schmidhuber, 1997) is an RNN with a cell state (long-term memory) and 3 gates that control the information flow, which solves the vanishing gradient problem.
  • Forget gate fₜ = σ(Wf[hₜ₋₁, xₜ] + bf): what to erase from memory.
  • Input gate iₜ = σ(…), candidate C̃ₜ = tanh(…): what new information to write.
  • Cell update: Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ C̃ₜ (additive, so the gradient flows easily).
  • Output gate oₜ = σ(…), hₜ = oₜ ⊙ tanh(Cₜ): what to output.

24. Bidirectional RNN (BRNN) 🔥 MUST ×2

Def: Two RNNs on the same input, one reading forward (past → future) and one backward (future → past). Their hidden states are concatenated, so each output uses both past and future context.
  • Uses: named entity recognition, speech recognition, translation, handwriting. Limitation: needs the whole sequence first, so it's not for real-time prediction; it costs twice the computation.
Yaad rakho: "Apple" fruit hai ya company? Aage ke words bhi padho, tabhi pata chalega. BRNN dono taraf se padhta hai.

25. Encoder–Decoder (Seq2Seq) 🔥 MUST

Def: An architecture where an encoder RNN/LSTM reads the input sequence into a fixed context vector, and a decoder RNN/LSTM generates the output sequence from it, so input and output lengths can differ.
  • Working: encoder reads "I love India" → final hidden state = context c → decoder starts with <START> and generates "मुझे भारत पसंद है <END>" word by word.
  • Teacher forcing: during training, the true previous word is fed to the decoder.
  • Problem: one fixed vector is a bottleneck for long sentences. Solution: attention (decoder looks at all encoder states).
  • Uses: translation, summarisation, chatbots, speech-to-text.
Yaad rakho: encoder = poora sentence sunke summary banata hai; decoder = summary se doosri bhasha mein bolta hai.

26. Deep learning pipeline for Speech Recognition (to LSTM evaluation) 🔥 MUST Part C

  1. Data collection: audio (.wav) + transcripts (e.g. LibriSpeech).
  2. Pre-processing: resample to 16 kHz, remove noise/silence, normalise, split into 25 ms frames with a 10 ms hop, apply a Hamming window.
  3. Feature extraction: MFCC (13–40 coefficients) or a log-Mel spectrogram for each frame.
  4. Labels: characters/phonemes + a "blank" token.
  5. Model: (CNN +) stacked Bidirectional LSTM layers → softmax over characters.
  6. Training: CTC loss (no frame-level alignment needed), Adam, dropout, early stopping.
  7. Decoding: greedy/beam search + language model.
  8. Evaluation: Word Error Rate WER = (S + D + I)/N (substitutions, deletions, insertions); lower is better. Also CER.
  9. Deployment: TFLite/ONNX on device, unidirectional LSTM for real-time.
Yaad rakho: awaaz → saaf karo → chhote tukde → MFCC fingerprint → BiLSTM → CTC → sentence → WER se check.

27. BPTT & Vanishing/Exploding gradients ⭐ HIGH

  • BPTT (backpropagation through time): unroll the RNN over T steps → it becomes a deep feed-forward net with shared weights → backprop through all steps → add up the gradients for the shared weights.
  • The gradient is multiplied by Whh at every step: < 1 → vanishes (0.5²⁰ ≈ 10⁻⁶), > 1 → explodes.
  • Fixes: truncated BPTT (only k steps), gradient clipping (for exploding), LSTM/GRU (for vanishing), ReLU, good initialisation.
Yaad rakho: lambi chain mein message "chinese whispers" ki tarah kho jaata hai = vanishing.

28. Applications & case studies (CV, speech, NLP) ⭐ HIGH

  • Computer vision: image captioning (CNN encoder + LSTM decoder), video activity recognition.
  • Speech: voice assistants, voice typing (above pipeline).
  • NLP: sentiment analysis, translation, text generation, chatbots.
  • Classification case study: movie review → embedding → LSTM → sigmoid (positive/negative).
  • Regression case study: stock/temperature forecasting → LSTM → linear output, MSE loss.
  • Recursive nets: apply the same weights over a tree structure (parse trees in NLP).

Unit 5 — AutoencodersAsked in ALL 3 papers · Part C in both 2025 papers

29. Autoencoders: basics, types & anomaly detection 🔥 MUST ×3

Def: An unsupervised neural network that learns to reconstruct its input. An encoder compresses x into a code h = f(x), and a decoder rebuilds r = g(h). It is trained to minimise the reconstruction loss L(x, g(f(x))).
  • Components: encoder, bottleneck/code (latent space), decoder, reconstruction loss (MSE/BCE).
  • Types: undercomplete, sparse, denoising, contractive (regularised), variational/stochastic, convolutional.
  • Anomaly detection: ① train only on normal data ② the AE reconstructs normal data well (low error) ③ an anomaly is reconstructed badly (high error) ④ set a threshold (e.g. mean + 3σ) ⑤ error > threshold → anomaly. Examples: credit-card fraud, machine-sensor faults, network intrusion, defective products.
  • Other applications: dimensionality reduction, denoising images, feature learning, image compression, pre-training.
Yaad rakho: AE ne sirf normal transactions dekhe hain; fraud aaya toh theek se copy nahi kar paaya → error zyada → alarm.

30. Undercomplete Autoencoder 🔥 MUST Part C

Def: An autoencoder whose code dimension is smaller than the input dimension (e.g. 784 → 32 → 784), so it is forced to learn the most important features.
  • How it avoids learning the identity function: the narrow bottleneck cannot simply copy x, so it must compress, keeping only the salient patterns.
  • With a linear decoder + MSE it learns the same subspace as PCA; with non-linear layers it is a more powerful non-linear PCA.
  • Caution: if the encoder/decoder are too powerful, it can still memorise, so keep the capacity limited.
  • Design for dimensionality reduction: 784 → 128 (ReLU) → 32 code → 128 (ReLU) → 784 (sigmoid), MSE loss, Adam. After training, use only the encoder to get the 32-D features.
Yaad rakho: 784 cheezein 32 ke dabbe mein bharni hain, toh sirf zaroori cheezein hi jaayengi. Copy-paste possible hi nahi.

31. Regularised Autoencoders (sparse, denoising, contractive) 🔥 MUST ×2

Def: Autoencoders that add a regularisation term or constraint to the loss instead of (or besides) a small bottleneck, so even an overcomplete AE learns useful features rather than copying.
  • Sparse AE: L = L(x, r) + λΣ|hᵢ| (or a KL penalty), so only a few neurons are active.
  • Denoising AE: corrupt x → x̃ (noise), train to reconstruct the clean x. It learns robust features.
  • Contractive AE: penalise the encoder's sensitivity (see topic 33).

32. Stochastic Encoders & Decoders ⭐ HIGH

Def: The encoder and decoder output probability distributions instead of fixed values: encoder penc(h|x), decoder pdec(x|h). Training minimises −log pdec(x|h).
  • VAE: the encoder outputs a mean μ and a standard deviation σ; sample z = μ + σ·ε (ε ~ N(0, 1), the reparameterisation trick); the decoder reconstructs.
  • Loss = reconstruction loss + KL(N(μ, σ²) ‖ N(0, 1)).
  • Can generate new samples (new faces, digits) and handles uncertainty.
Yaad rakho: fixed answer nahi, ek "range" deta hai, usme se random pick karke naya data bana sakta hai.

33. Contractive Autoencoder (CAE) ⭐ HIGH

Def: A regularised AE that adds a penalty on the Frobenius norm of the encoder's Jacobian: L = L(x, g(f(x))) + λ‖∂f(x)/∂x‖²F.
  • Makes the code insensitive to small input changes, so the features are robust (it "contracts" the neighbourhood around each training point).
  • vs Denoising AE: DAE gets robustness by adding noise to the input; CAE gets it analytically through the Jacobian penalty on the encoder.
Yaad rakho: photo thodi si hili ya noise aaya, phir bhi code wahi rehna chahiye. Yahi "contractive" hai.

⏰ Last-hour 2-mark list (Part A)Read this just before the exam

  1. Deep Learning: ML using many-layered neural networks that learn hierarchical features automatically from raw data. It powers vision, speech and NLP.
  2. Curse of dimensionality: the space grows exponentially with features, so data becomes sparse and needs exponentially more samples, which causes overfitting.
  3. Backpropagation: computes loss gradients for all weights using the chain rule from output to input, then updates them by gradient descent.
  4. SGD: updates weights using one random sample at a time: w ← w − η∇Lᵢ. Fast but noisy.
  5. MLP: a feed-forward network with input, ≥1 non-linear hidden layer and an output layer, trained with backprop.
  6. Deep feed-forward network: information flows only forward, with no loops; it is a chain of layers approximating f*(x).
  7. Two activation functions: ReLU = max(0, z); Sigmoid = 1/(1 + e⁻ᶻ).
  8. LReLU vs ReLU: LReLU gives a small slope (0.01z) for negative inputs, which solves the dying ReLU problem.
  9. Supervised vs unsupervised training: supervised uses labelled (x, y) to predict y; unsupervised uses only x to find structure (clustering, autoencoders).
  10. RBM: a two-layer (visible–hidden) energy-based generative network with no intra-layer connections, trained by contrastive divergence.
  11. ML vs DL: ML needs hand-crafted features and less data; DL learns features itself but needs big data and GPUs.
  12. Parameter sharing: the same filter weights at all image positions → far fewer parameters + translation equivariance.
  13. CNN applications: image classification, object detection, face recognition, medical imaging, self-driving cars.
  14. CNN regularisation technique: dropout (randomly drop neurons during training); also L2, data augmentation.
  15. DL in computer vision: e.g. face recognition / tumour detection in MRI using CNNs.
  16. BRNN: two RNNs reading the sequence forward and backward; their states are concatenated to use past + future context.
  17. Encoder–decoder: the encoder compresses the input sequence into a context vector; the decoder generates the output sequence from it (translation).
  18. LSTM: an RNN with a cell state and forget/input/output gates that keeps long-term memory and avoids vanishing gradients.
  19. BPTT: backprop on the RNN unrolled through time, adding up the gradients of the shared weights.
  20. Autoencoder application: anomaly/fraud detection, denoising, dimensionality reduction.
  21. Regularised AE purpose: adds a penalty (sparsity/noise/Jacobian) so the AE learns useful features instead of copying the input.
  22. Regularised vs stochastic AE: regularised = deterministic mapping + penalty term; stochastic = probabilistic encoder/decoder p(h|x), p(x|h) (e.g. VAE).
  23. Undercomplete AE: code dimension < input dimension, so it must learn a compressed representation.
  24. Contractive AE: penalises ‖∂h/∂x‖², so the code is robust to small input changes.
