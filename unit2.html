Q1 🔥 MUST DO★★★☆☆ 2 / 4 / 10 marks PYQ 2025 C2 + A4PYQ 2024 A67CAI 2025 B7 + A9
How is an unsupervised neural network trained? Explain in detail with an example. Differentiate supervised and unsupervised training.
📝 Exam answer

Unsupervised training means training a neural network on unlabelled data (only X, no y). There is no "correct answer", so the network learns by optimising an objective made from the data itself: reconstructing the input, modelling its probability distribution, or grouping similar inputs.

Main approaches

  1. Autoencoders (reconstruction-based): encoder compresses x to code h, decoder rebuilds x̂. Loss = reconstruction error
    L = ‖x − x̂‖² (MSE) or binary cross-entropy
    Trained with ordinary backprop + SGD, using the input itself as the target.
  2. Energy-based models / RBMs: learn the probability distribution p(v) of the data. Trained with Contrastive Divergence (CD-k): ΔW = η(⟨vhᵀ⟩data − ⟨vhᵀ⟩recon).
  3. Competitive learning / Self-Organising Maps (Kohonen): neurons compete; the winner (closest weight vector) and its neighbours move towards the input: w ← w + η(x − w). The result is clustering and a topology-preserving map.
  4. Hebbian learning: "neurons that fire together wire together": Δw = η·x·y.
  5. Generative models: GANs, VAEs. Self-supervised learning: predict the masked or next part of the data.

Greedy layer-wise unsupervised pre-training (classic deep-net method)

  1. Train layer 1 (an RBM or autoencoder) on raw input x and get features h₁.
  2. Freeze it, then train layer 2 on h₁ to get h₂, and so on. Each layer learns a higher-level representation.
  3. Stack the layers to form a deep network (a Deep Belief Network or stacked autoencoder).
  4. Fine-tune the whole network with backprop using a small amount of labelled data (optional).

Benefits: good initial weights, avoids poor local minima and vanishing gradients, uses cheap unlabelled data.

Worked example: compressing handwritten digits (MNIST)

Data: 60,000 images, 28×28 = 784 pixels, labels NOT used.
Network: 784 → 256 → 64 (code) → 256 → 784   (autoencoder)
Step 1: forward pass  x → h (64 numbers) → x̂ (784 pixels)
Step 2: loss = mean (x − x̂)²   e.g. epoch 1: 0.090 … epoch 20: 0.012
Step 3: backprop + Adam update all weights; repeat for epochs
Result: the 64-number code captures stroke shape. Similar digits
        get similar codes, so k-means on the codes groups the 0s, 1s, 2s…
        without ever seeing a label.

(Loss values are illustrative.)

Q2 🔥 MUST DO★★★★☆ 2 / 4 / 10 marks PYQ 2025 A6PYQ 2024 A77CAI 2025 B2
What are Restricted Boltzmann Machines (RBMs)? Explain their architecture and working principle.
📝 Exam answer

Definition: An RBM is a two-layer, generative, energy-based stochastic neural network that learns the probability distribution of its input in an unsupervised way. Proposed by Smolensky (1986) and made popular by Geoffrey Hinton.

Architecture

  • Visible layer v (input units, e.g. pixels) and hidden layer h (feature detectors). Units are usually binary (0/1).
  • Every visible unit is connected to every hidden unit with symmetric (undirected) weights W.
  • "Restricted": there are no connections within a layer (no v–v or h–h edges), so the graph is bipartite. This makes sampling easy.
  • Biases: a for visible units, b for hidden units.

Energy and probability

E(v, h) = − aᵀv − bᵀh − vᵀW h
P(v, h) = e−E(v,h) / Z , Z = Σv,h e−E(v,h) (partition function)

Low energy means a high probability configuration. Training lowers the energy of real data.

Conditional probabilities (easy because of the bipartite structure):

P(hⱼ = 1 | v) = σ( bⱼ + Σᵢ vᵢ wᵢⱼ )
P(vᵢ = 1 | h) = σ( aᵢ + Σⱼ wᵢⱼ hⱼ ) where σ = sigmoid

Working / training: Contrastive Divergence (CD-1)

  1. Positive phase: put a training sample v⁽⁰⁾ on the visible layer, compute P(h|v⁽⁰⁾) and sample h⁽⁰⁾.
  2. Reconstruction (negative phase): from h⁽⁰⁾ compute P(v|h⁽⁰⁾) and get the reconstruction v⁽¹⁾; then compute h⁽¹⁾ from v⁽¹⁾.
  3. Update:
    ΔW = η ( v⁽⁰⁾h⁽⁰⁾ᵀ − v⁽¹⁾h⁽¹⁾ᵀ ) , Δa = η(v⁽⁰⁾ − v⁽¹⁾) , Δb = η(h⁽⁰⁾ − h⁽¹⁾)
  4. Repeat for all data and epochs. The reconstruction becomes closer and closer to the real data.

Idea: "data statistics − model statistics". Increase the probability of real data and decrease the probability of the model's own fantasies.

Applications

  • Feature learning and dimensionality reduction
  • Collaborative filtering / recommender systems (Netflix Prize)
  • Pre-training of deep networks: stacking RBMs gives a Deep Belief Network (DBN) (Hinton, 2006)
  • Classification, topic modelling, image denoising

Limitations

Z is intractable, so exact likelihood can't be computed; training is tricky (CD is only approximate). Today it is largely replaced by autoencoders/VAEs and GANs.

💜 Hinglish samjho

RBM mein sirf 2 layers hain: visible (jo data dikhta hai) aur hidden (chhupe features). Har visible har hidden se juda hai, par ek hi layer ke andar koi connection nahi, isliye "Restricted". Kaam: data → hidden features banao → unse data wapas banao (reconstruct) → asli aur bane hue ka difference dekh ke weights update karo (contrastive divergence). Energy kam = woh pattern zyada "natural". Kai RBMs stack karo toh Deep Belief Network.

🟢 Easy example (English)

Movie recommendation: the visible units are movies you liked (1/0). The hidden units learn "taste features" like likes action or likes romance. From your hidden tastes, the RBM reconstructs the visible layer and switches on movies you haven't watched yet but will probably like.

🌸 आसान उदाहरण (हिंदी)

फ़िल्म सुझाव: दिखने वाली परत (visible) = आपको पसंद आई फ़िल्में। छिपी परत (hidden) = आपकी "रुचि" जैसे एक्शन पसंद, कॉमेडी पसंद। इन रुचियों से RBM वापस फ़िल्मों की सूची बनाता है और ऐसी नई फ़िल्में सुझाता है जो आपने अभी तक नहीं देखीं पर पसंद आएँगी।

Q3 🔥 MUST DO★★★☆☆ 2 / 4 / 10 marks PYQ 2025 A3 + B3PYQ 2024 A57CAI 2025 A2
Explain activation functions: ReLU, Leaky ReLU, ELU (and sigmoid, tanh, softmax). Analyse the effect of different activation functions on a network's performance with an example.
📝 Exam answer

An activation function decides a neuron's output from its weighted input z = Σwx + b. It adds non-linearity. Without it, any deep network collapses into one linear model and cannot learn complex patterns.

FunctionFormula f(z)Derivative f′(z)RangeProsCons
Sigmoid1 / (1 + e−z)f(1 − f), max 0.25(0, 1)Probability outputVanishing gradient, not zero-centred
Tanh(ez − e−z)/(ez + e−z)1 − f², max 1(−1, 1)Zero-centredStill saturates, so vanishing gradient
ReLUmax(0, z)1 if z > 0, else 0[0, ∞)Simple, fast, no vanishing for z > 0, sparseDying ReLU (z < 0 gives gradient 0)
Leaky ReLUz if z > 0, else αz (α = 0.01)1 or α(−∞, ∞)Fixes dying ReLUα is a fixed guess (PReLU learns α)
ELUz if z > 0, else α(ez − 1)1 or f(z) + α(−α, ∞)Smooth, mean output near 0, faster convergence, robust to noiseexp() is slower to compute
Softmaxezᵢ / Σⱼ ezⱼ—(0, 1), sum = 1Multi-class probabilitiesOnly for the output layer

Worked values (z = −2, 0, 2)

             z = −2      z = 0     z = 2
Sigmoid      0.1192      0.5       0.8808
Tanh        −0.9640      0         0.9640
ReLU         0           0         2
Leaky ReLU  −0.02        0         2        (α = 0.01)
ELU         −0.8647      0         2        (α = 1:  e^−2 − 1 = 0.1353 − 1)

Softmax of logits [2, 1, 0.1]:
e^2 = 7.389, e^1 = 2.718, e^0.1 = 1.105, sum = 11.212
→ probabilities [0.659, 0.242, 0.099]  (sum = 1)

Effect on performance (analysis)

  • Vanishing gradient with sigmoid/tanh: σ′ ≤ 0.25. In a 10-layer sigmoid network the gradient is multiplied by ≤ 0.25 ten times: 0.25¹⁰ ≈ 9.5 × 10⁻⁷. Early layers almost stop learning, so training is very slow.
  • ReLU has gradient 1 for z > 0, so the gradient flows freely. Deep networks (AlexNet) trained about 6× faster with ReLU than with tanh.
  • Dying ReLU: if a neuron's z stays negative (e.g. after a large learning-rate update), its output and gradient are always 0, so it never recovers. Many dead neurons reduce model capacity.
  • Problem LReLU solves: it gives a small slope α for z < 0, so the gradient is never exactly zero and dead neurons can recover.
  • ELU: negative outputs push the mean activation towards 0. This acts like batch-norm, speeds up convergence and often gives slightly better accuracy.
  • Choice: hidden layers use ReLU (default), LReLU/ELU if neurons die; output uses sigmoid (binary), softmax (multi-class), linear (regression).

Example experiment: train the same 5-hidden-layer MLP on MNIST for 5 epochs. Typically sigmoid gives the slowest progress (loss decreases slowly because of vanishing gradients), while ReLU/LReLU/ELU reach about 97–98% test accuracy. ELU and LReLU are a little more stable when the learning rate is high. (These are typical observed trends; exact numbers vary.)

💜 Hinglish samjho

Activation function = neuron ka "switch" jo decide karta hai kitna signal aage bhejna hai, aur network ko non-linear banata hai. Sigmoid/tanh bade inputs pe flat ho jaate hain, gradient chhota ho jaata hai (vanishing), toh deep network seekhta hi nahi. ReLU = negative ko 0, positive ko waisa hi, fast aur simple. Par negative side pe gradient 0, toh neuron "mar" sakta hai (dying ReLU). Leaky ReLU negative side pe thoda slope (0.01z) deta hai taaki neuron zinda rahe. ELU negative side pe smooth curve deta hai jo −α tak jaata hai.

🟢 Easy example (English)

Think of a water tap. ReLU: if the pressure is negative, no water at all; if positive, water flows as much as the pressure. Leaky ReLU: even at negative pressure a few drops leak, so the pipe never fully dries up and jams. Sigmoid: a tap that can only open between 0 and 100%. Pushing harder at the extremes changes nothing (saturation).

🌸 आसान उदाहरण (हिंदी)

पानी का नल सोचिए। ReLU: दबाव नकारात्मक हो तो पानी बिल्कुल बंद, सकारात्मक हो तो जितना दबाव उतना पानी। Leaky ReLU: नकारात्मक दबाव पर भी कुछ बूँदें टपकती रहती हैं, ताकि पाइप पूरी तरह सूखकर जाम न हो। Sigmoid: नल 0 से 100% तक ही खुलता है — उसके बाद ज़ोर लगाने से कुछ नहीं बदलता।

Q4 🔥 MUST DO★★☆☆☆ 2 / 10 marks PYQ 2025 A1PYQ 2024 A1 + A37CAI 2025 C1 + A6
Define Deep Learning and its significance / scope in AI. Differentiate Machine Learning and Deep Learning, and explain how deep learning improves representation power over traditional ML.
📝 Exam answer

Deep Learning is a subset of machine learning that uses artificial neural networks with many hidden layers to automatically learn hierarchical representations (features) from raw data such as images, text and audio.

AI ⊃ ML ⊃ DL: AI = machines acting intelligently; ML = learning from data; DL = ML with deep neural networks.

Significance / scope in AI: state-of-the-art results in computer vision, speech recognition, NLP and translation, medical imaging, self-driving cars, recommendation systems and generative AI (ChatGPT, image generation). It scales with big data and GPUs, and removes the need for manual feature engineering.

PointMachine LearningDeep Learning
FeaturesHand-crafted by experts (feature engineering)Learned automatically from raw data
Data neededWorks with small/medium dataNeeds large data; performance keeps rising with data
HardwareCPU is enoughGPU/TPU needed
Training timeShort (minutes)Long (hours to weeks)
ModelsLinear/logistic regression, SVM, decision tree, k-NN, random forestMLP, CNN, RNN/LSTM, autoencoders, transformers
InterpretabilityEasier to explain"Black box"
Problem solvingBreaks the problem into partsEnd-to-end learning
Best forStructured / tabular dataUnstructured data: images, audio, text

How DL improves representation power

  • Hierarchical features: layer 1 learns edges, layer 2 shapes, layer 3 parts, the last layer whole objects. Traditional ML uses one fixed feature set (e.g. SIFT/HOG) designed by a human.
  • Composition of non-linear functions: depth lets the network represent very complex functions with fewer units (exponential efficiency).
  • Distributed representations: each concept is encoded by many neurons, and each neuron takes part in many concepts, which gives far more expressiveness than one-hot features.
  • End-to-end optimisation: features and classifier are learned together for the task.

Example: Cat vs dog images. ML pipeline: engineer HOG + colour histogram, then an SVM gives roughly 80% accuracy and needs expert effort. DL: a CNN takes raw pixels, learns its own features and reaches 95%+ with enough data (typical figures).

💜 Hinglish samjho

ML mein insaan ko batana padta hai ki "kaunse features dekho" (feature engineering). DL mein network khud raw data se features nikaal leta hai, layer-by-layer: pehle edges, phir shapes, phir pura object. Isliye DL ko bahut data aur GPU chahiye, par images, voice aur text pe jabardast kaam karta hai.

🟢 Easy example (English)

ML is like a student who is given a checklist: "a cat has pointy ears, whiskers, small nose". DL is like a child who sees thousands of cat photos and figures out on their own what makes a cat a cat.

🌸 आसान उदाहरण (हिंदी)

ML: शिक्षक ने सूची दी — "बिल्ली के नुकीले कान, मूँछें, छोटी नाक होती है" — उसी से पहचानो। DL: बच्चा हज़ारों बिल्लियों की तस्वीरें देखकर खुद समझ जाता है कि बिल्ली कैसी दिखती है। किसी ने विशेषताएँ नहीं बताईं।

Q5 ⭐ HIGH★★★☆☆ 4 / 10 marks 7CAI 2025 C2
What is Representation Learning? Explain how deep learning automates feature engineering, with an example from image or speech recognition.
📝 Exam answer

Representation learning is a set of techniques that let a system automatically discover the features (representations) needed for a task from raw data, instead of hand-designing them. A good representation makes the later task (classification, regression, clustering) easy, often linearly separable.

How DL automates feature engineering

  1. Raw input (pixels / audio samples) goes straight into the network.
  2. Each hidden layer transforms its input: h = f(Wx + b). The weights W are learned by backprop, so the features are learned, not designed.
  3. Hierarchy: low layers capture simple patterns, deeper layers combine them into abstract concepts.
  4. The last layer uses these learned features for the task (softmax classifier).

Types

  • Supervised: CNN features learned while training a classifier.
  • Unsupervised: autoencoders, RBMs, PCA (linear).
  • Self-supervised: word2vec, BERT (predict masked words), contrastive learning.
  • Transfer learning: reuse ImageNet CNN features for a new task with little data.

Example: face recognition (image)

Pixels → Layer 1: edges, colour blobs → Layer 2: corners, textures, contours → Layer 3: eyes, nose, mouth → Layer 4: whole faces / identity. Earlier systems needed hand-made features (Haar, HOG, SIFT).

Example: speech recognition

Old pipeline: hand-designed MFCC features + HMM/GMM. Deep pipeline: spectrogram → CNN/LSTM layers learn phoneme-like features → words. Learned features gave large drops in word error rate.

💜 Hinglish samjho

Pehle engineers khud baithke features banate the (edges kaise detect karein, MFCC kaise nikaalein). Representation learning mein network yeh kaam khud karta hai. Har layer pichhli layer ke features ko jodke zyada "samajhdaar" features banati hai: edges → shapes → aankh/naak → chehra. Isi ko "DL automates feature engineering" kehte hain.

🟢 Easy example (English)

Learning to read: first you recognise strokes, then letters, then words, then sentences and their meaning. Nobody hands you a rule for each word; you build up from simple pieces. A deep network builds features the same way.

🌸 आसान उदाहरण (हिंदी)

पढ़ना सीखना: पहले रेखाएँ पहचानते हैं, फिर अक्षर, फिर शब्द, फिर वाक्य और उनका अर्थ। हर शब्द का नियम कोई नहीं बताता — हम छोटे टुकड़ों से बड़ी समझ बनाते हैं। डीप नेटवर्क भी इसी तरह परत-दर-परत विशेषताएँ खुद सीखता है।

Q6 ⭐ HIGH★★☆☆☆ 2 / 4 marks
Explain the width and depth of neural networks. Why are deeper networks preferred?
📝 Exam answer
  • Width = number of neurons in a layer.
  • Depth = number of layers (hidden + output) with learnable weights.
PointWide & shallowNarrow & deep
What it capturesMany features at one levelHierarchical, compositional features
Parameters for the same powerCan need exponentially many neuronsFar fewer parameters
TrainingEasier, parallel, fewer gradient problemsVanishing/exploding gradients, harder to optimise
OverfittingRisk with very large widthRisk with depth; needs regularisation
Example1 hidden layer with 10,000 unitsResNet-152 (152 layers)

Why depth helps: (1) The Universal Approximation Theorem says one wide layer is enough in theory, but it may need exponentially many units; (2) deep networks reuse features (composition), giving exponential gains in expressiveness; (3) they match the hierarchical structure of real data. Making depth trainable: ReLU, batch normalisation, residual (skip) connections, good initialisation (He/Xavier). Balance: EfficientNet scales width, depth and resolution together.

💜 Hinglish samjho

Width = ek layer mein kitne neurons (chaudai). Depth = kitni layers (gehraai). Zyada gehra network chhote-chhote features jodke complex cheezein kam parameters mein seekh leta hai. Par bahut deep ho toh gradient gayab, isliye ReLU, BatchNorm, ResNet skip connections use karte hain.

🟢 Easy example (English)

A company: a wide company has 1,000 workers who all report to one boss (flat). A deep company has a few levels: workers → supervisors → managers → CEO. Information gets summarised at each level, which handles complex work with fewer people.

🌸 आसान उदाहरण (हिंदी)

कंपनी: चौड़ी कंपनी में 1000 कर्मचारी सीधे एक बॉस को रिपोर्ट करते हैं। गहरी कंपनी में कर्मचारी → सुपरवाइज़र → मैनेजर → CEO। हर स्तर पर जानकारी का सार बनता है, इसलिए कम लोगों में जटिल काम हो जाता है।

⚡ Part-A quick answers (2 marks, ~25 words each)

  1. Define Deep Learning and its significance in AI. A subset of ML using multi-layer neural networks that automatically learn hierarchical features from raw data; it drives modern AI in vision, speech and NLP. 2025 A1 2024 A1
  2. Two activation functions? ReLU: f(z) = max(0, z). Sigmoid: f(z) = 1/(1 + e⁻ᶻ), output in (0, 1). Others: tanh, Leaky ReLU, ELU, softmax. 2025 A3 2024 A5
  3. Supervised vs unsupervised training? Supervised learns from labelled pairs (x, y) to predict y; unsupervised uses only x to find structure (clusters, compressed features). 2025 A4 7CAI A9
  4. What are RBMs? Two-layer (visible-hidden) undirected energy-based generative networks with no intra-layer links, trained unsupervised via contrastive divergence. 2025 A6 2024 A7
  5. What problem does Leaky ReLU solve? The "dying ReLU" problem: it uses a small slope (αz, α = 0.01) for negative inputs so the gradient is never zero and neurons can recover. 7CAI A2
  6. ML vs DL (one line)? ML needs hand-crafted features and less data; DL learns features automatically from raw data but needs large data and GPUs. 2024 A3
  7. Unsupervised training in NNs? Training without labels by minimising reconstruction error (autoencoders), modelling data probability (RBM/CD) or competitive clustering (SOM). 2024 A6
  8. Major use of DL in computer vision? Image classification/object detection with CNNs, e.g. face recognition and medical image diagnosis. 7CAI A6
  9. Scope of deep learning? Vision, speech, NLP, healthcare, autonomous vehicles, finance, recommendation and generative AI; it grows with data and compute. 2024 A1
  10. Representation learning? Automatically learning useful features from raw data instead of manual feature engineering, e.g. CNN layers learning edges → shapes → objects.
  11. ELU? f(z) = z for z > 0, α(eᶻ − 1) for z ≤ 0. It is smooth, gives a near-zero mean output, avoids dead neurons and converges faster.
  12. Contrastive divergence? An approximate RBM training method: ΔW = η(v₀h₀ᵀ − v₁h₁ᵀ), using one Gibbs step of reconstruction.
  13. Deep Belief Network? A stack of RBMs trained greedily layer by layer (unsupervised), then fine-tuned with backprop.
  14. Width vs depth? Width = neurons per layer; depth = number of layers. Depth gives hierarchical features with fewer parameters.
