Q1 🔥 MUST DO★★★★☆ 2 / 4 / 10 marksPYQ 2025 A5 + B4PYQ 2024 A27CAI 2025 B1
Explain the Backpropagation algorithm. Derive the weight update rule for an MLP. Solve for updated weights for a single-layer perceptron with given inputs, weights and target.
📝 Exam answer

Definition: Backpropagation (backward propagation of errors) is a supervised learning algorithm that trains a neural network by computing the gradient of the loss with respect to every weight using the chain rule, moving from the output layer back to the input layer. Then gradient descent updates the weights.

Steps

  1. Initialise weights and biases with small random values; choose learning rate η.
  2. Forward pass: for each layer compute net = Σ wᵢxᵢ + b and output o = f(net).
  3. Compute error / loss: e.g. E = ½ Σ (t − o)².
  4. Backward pass: compute error term δ for each neuron.
    Output neuron: δₖ = (tₖ − oₖ) · f′(netₖ)
    Hidden neuron: δⱼ = f′(netⱼ) · Σₖ wⱼₖ δₖ
  5. Update weights: Δwᵢⱼ = η · δⱼ · xᵢ , wnew = wold + Δw
  6. Repeat for all samples and many epochs until the error is small.

For sigmoid, f′(net) = o(1 − o). For ReLU, f′ = 1 if net > 0 else 0.

Derivation of the weight update rule (MLP, sigmoid, E = ½Σ(tₖ − oₖ)²) 7CAI 2025 B1

Gradient descent:  Δw = −η ∂E/∂w

(a) Hidden→output weight wⱼₖ   (netₖ = Σⱼ wⱼₖ hⱼ ,  oₖ = σ(netₖ))
    ∂E/∂wⱼₖ = ∂E/∂oₖ · ∂oₖ/∂netₖ · ∂netₖ/∂wⱼₖ          (chain rule)
            = −(tₖ − oₖ) · oₖ(1 − oₖ) · hⱼ
    Let δₖ = (tₖ − oₖ) oₖ(1 − oₖ)   ⇒   Δwⱼₖ = η δₖ hⱼ

(b) Input→hidden weight wᵢⱼ   (netⱼ = Σᵢ wᵢⱼ xᵢ ,  hⱼ = σ(netⱼ))
    hⱼ affects every output k, so sum over k:
    ∂E/∂wᵢⱼ = Σₖ [∂E/∂netₖ · ∂netₖ/∂hⱼ] · ∂hⱼ/∂netⱼ · ∂netⱼ/∂wᵢⱼ
            = Σₖ (−δₖ wⱼₖ) · hⱼ(1 − hⱼ) · xᵢ
    Let δⱼ = hⱼ(1 − hⱼ) Σₖ wⱼₖ δₖ   ⇒   Δwᵢⱼ = η δⱼ xᵢ

General rule:  w_new = w_old + η · δ(of receiving neuron) · input(to that weight)

Variants of backpropagation

  • Batch (full) GD: update after the whole dataset.
  • Stochastic GD: update after every single sample.
  • Mini-batch GD: update after small batches (32, 64…), used in practice.
  • With momentum / Nesterov, AdaGrad, RMSProp, Adam: smarter step sizes.
  • BPTT: backprop through time for RNNs (Unit 4).

Advantages / limitations

  • ✔ Efficient (one forward + one backward pass), works for any differentiable network.
  • ✘ Vanishing/exploding gradients in deep nets, can get stuck in local minima, needs labelled data, sensitive to η.
🧮 Solved numerical 1: perceptron (step function) — the type asked in 2025 B4

Given: x₁ = 1, x₂ = 1, w₁ = 0.5, w₂ = −0.4, bias b = −0.2, target t = 1, η = 0.1, activation = step (o = 1 if net ≥ 0 else 0).

net = w1·x1 + w2·x2 + b = 0.5(1) + (−0.4)(1) + (−0.2) = −0.1
o   = step(−0.1) = 0          error = t − o = 1 − 0 = 1

Perceptron rule: w_new = w + η (t − o) x
w1 = 0.5  + 0.1(1)(1) = 0.6
w2 = −0.4 + 0.1(1)(1) = −0.3
b  = −0.2 + 0.1(1)    = −0.1

Check: net = 0.6 − 0.3 − 0.1 = 0.2 ≥ 0  →  o = 1 = target ✔
🧮 Solved numerical 2: sigmoid neuron with gradient descent (delta rule)

Given: x₁ = 1, x₂ = 0.5, w₁ = 0.4, w₂ = 0.6, b = 0, t = 1, η = 0.5, sigmoid activation, E = ½(t − o)².

Forward:  net = 0.4(1) + 0.6(0.5) + 0 = 0.7
          o   = 1 / (1 + e^−0.7) = 1 / 1.4966 = 0.6682
          error (t − o) = 0.3318

Backward: δ = (t − o) · o(1 − o) = 0.3318 × 0.6682 × 0.3318 = 0.0736

Update:   Δw1 = η δ x1 = 0.5 × 0.0736 × 1   = 0.0368 → w1 = 0.4368
          Δw2 = η δ x2 = 0.5 × 0.0736 × 0.5 = 0.0184 → w2 = 0.6184
          Δb  = η δ    = 0.0368              → b  = 0.0368

Check:    new net = 0.7828 → o = 0.6863  (error falls 0.3318 → 0.3137 ✔)

Always end with a "check" line. It shows the examiner that the error went down.

💜 Hinglish samjho

Network ne answer diya, answer galat tha. Ab "galti kiski hai?" yeh pata karna hai. Backprop output se peeche ki taraf jaata hai aur har weight ko batata hai ki "tumhari wajah se itni galti hui" (yahi gradient hai). Phir har weight thoda sa adjust hota hai: naya weight = purana + η × δ × input. Yeh baar-baar (epochs) karo, galti kam hoti jaayegi.

🟢 Easy example (English)

A cricket team loses a match. The coach goes backwards through the game: last over → bowlers → batting order, and gives each player feedback in proportion to their mistake. Next match everyone corrects a little. That's backpropagation.

परीक्षा में कम नंबर आए। आप पीछे की ओर देखते हैं — किस अध्याय में गलती हुई, कितनी हुई — और अगली बार उसी हिसाब से पढ़ाई बदलते हैं। जिस अध्याय में ज़्यादा गलती, उस पर ज़्यादा सुधार। यही बैकप्रोपेगेशन है।

Q2 🔥 MUST DO★★☆☆☆ 2 / 4 marksPYQ 2025 A2 + B1PYQ 2024 A4
What is the Curse of Dimensionality? Given a high-dimensional dataset, how would you address it using deep learning techniques?
📝 Exam answer

Definition: The curse of dimensionality (term by Richard Bellman) refers to the problems that arise when the number of features (dimensions) becomes very large. The volume of the space grows exponentially, so the available data becomes sparse, and models need exponentially more data to generalise.

Problems caused

  • Data sparsity: with 10 bins per feature, d features need 10ᵈ cells (1D = 10, 2D = 100, 3D = 1000, 10D = 10¹⁰).
  • Distances lose meaning: nearest and farthest points become almost equally far, so k-NN and clustering fail.
  • Overfitting: too many features and too few samples, so the model memorises noise.
  • High computation and memory cost.
  • Hughes phenomenon: beyond a point, adding features reduces accuracy.

How deep learning addresses it

  1. Autoencoders: a bottleneck layer learns a low-dimensional code (non-linear PCA).
  2. Representation learning: hidden layers learn compact, useful features automatically.
  3. CNNs: local connectivity and parameter sharing cut parameters massively; pooling reduces spatial size.
  4. Embeddings: words or categories mapped from huge one-hot vectors to small dense vectors (e.g. 50,000 → 300).
  5. Regularisation: dropout, L1 (also does feature selection), L2, early stopping.
  6. Data augmentation to increase the effective sample size; PCA / feature selection as preprocessing.
💜 Hinglish samjho

Features (columns) jitne zyada, space utna bada, aur data utna "khaali-khaali" lagta hai. Model ko pattern seekhne ke liye bahut zyada data chahiye hota hai. Solution: features ko compress karo (autoencoder, PCA, embeddings), parameters kam karo (CNN sharing), aur overfitting roko (dropout, regularisation).

🟢 Easy example (English)

Finding a friend on a single road (1D) is easy. Finding them in a whole city (2D) is harder. Finding them in a 100-floor building complex with many towers (3D+) is very hard with the same number of clues. More dimensions mean more searching for the same amount of information.

🌸 आसान उदाहरण (हिंदी)

एक लाइन में खोई हुई अंगूठी ढूँढना आसान है, पूरे खेत (2D) में मुश्किल, और पूरी बिल्डिंग (3D) में बहुत मुश्किल। जितने ज़्यादा आयाम (dimensions), उतना ज़्यादा डेटा चाहिए — यही "आयामों का अभिशाप" है।

💡 Exam tip

Always write the "10ᵈ cells" example. It is the fastest way to prove you understand. For the B1 (4 marks) version, list 4–5 DL techniques with one line each.

Q3 🔥 MUST DO★★★☆☆ 2 / 4 / 10 marksPYQ 2025 A9
Explain Stochastic Gradient Descent (SGD). Compare it with Batch and Mini-batch Gradient Descent. Explain its variants.
📝 Exam answer

Gradient Descent minimises the loss by moving the weights opposite to the gradient:

w ← w − η · ∂L/∂w (η = learning rate)

Stochastic Gradient Descent computes the gradient on one randomly picked training sample at a time and updates the weights immediately:

for each sample i (shuffled): w ← w − η · ∇Li(w)

Algorithm

  1. Initialise w, choose η.
  2. Shuffle the training data.
  3. For each sample: forward pass → loss → gradient → update w.
  4. Repeat for several epochs until convergence.
PointBatch GDStochastic GDMini-batch GD
Data per updateWhole dataset1 sampleSmall batch (32–256)
Updates per epoch1NN / batch size
Path to minimumSmoothNoisy, zig-zagFairly smooth
Speed / memorySlow, high memoryFast, low memoryBest balance, GPU friendly
Local minimaCan get stuckNoise helps escapeSome escape

Variants (improvements)

  • Momentum: v = βv + η∇L, w = w − v. Adds "velocity", which reduces zig-zag (β ≈ 0.9).
  • Nesterov (NAG): looks ahead before computing the gradient.
  • AdaGrad: per-parameter learning rate, larger for rare features.
  • RMSProp: uses a moving average of squared gradients so the learning rate doesn't shrink to zero.
  • Adam: Momentum + RMSProp; the default choice in deep learning.
💜 Hinglish samjho

Batch GD: poori class ki copies check karke ek baar feedback. SGD: har ek student ki copy dekhte hi turant feedback, isliye fast hai par thoda "hilta-dulta" (noisy) hai. Mini-batch: 32-32 copies ka group, dono ka best. Momentum = gaadi ki speed, chhote gaddhon (zig-zag) mein nahi atakti. Adam = sabse smart, default.

🟢 Easy example (English)

You are blindfolded on a hill and want to reach the valley. You feel the slope under your feet and take a small step downhill. Step size = learning rate. If you decide each step after asking only one random friend for directions (SGD), you move fast but wobble. Asking everyone first (Batch GD) is slow but steady.

🌸 आसान उदाहरण (हिंदी)

आँखों पर पट्टी बाँधकर पहाड़ से नीचे उतरना है। पैरों से ढलान महसूस करो और नीचे की तरफ़ छोटा कदम रखो। कदम का आकार = learning rate। हर कदम पर सिर्फ़ एक दोस्त से रास्ता पूछना = SGD (तेज़ पर डगमगाता हुआ)।

💡 Exam tip

The comparison table alone can earn 4 marks. For 2 marks: "SGD updates weights using the gradient of one random sample at a time: w ← w − η∇Lᵢ. It is fast and memory-efficient but noisy."

Q4 🔥 MUST DO★★★☆☆ 4 / 10 marksPYQ 2025 B27CAI 2025 A1
Explain the Multilayer Perceptron (MLP). Design a simple neural network with three layers for binary classification and explain its working.
📝 Exam answer

MLP: a fully-connected feed-forward neural network with an input layer, one or more hidden layers with non-linear activation, and an output layer. Every neuron computes a = f(Σwx + b). It is trained with backpropagation and can learn non-linear decision boundaries (e.g. XOR), which a single perceptron cannot.

Design: binary classification (e.g. "Will a student pass? Yes/No")

LayerNeuronsActivationRole
Input2 (hours studied, attendance %)nonePasses the features forward
Hidden3 (or 4–16)ReLULearns non-linear feature combinations
Output1SigmoidGives probability P(pass) in 0–1
  • Loss: Binary cross-entropy L = −[y log ŷ + (1 − y) log(1 − ŷ)]
  • Optimiser: SGD / Adam, learning rate 0.01
  • Decision: if ŷ ≥ 0.5 → class 1 (Pass), else class 0 (Fail)

Working

  1. Forward pass: h = ReLU(W₁x + b₁) → ŷ = σ(W₂h + b₂).
  2. Loss compares ŷ with the true label y.
  3. Backpropagation finds gradients; gradient descent updates W₁, b₁, W₂, b₂.
  4. Repeat over epochs; evaluate with accuracy, precision, recall on test data.

Parameter count: (2×3 + 3) + (3×1 + 1) = 9 + 4 = 13 parameters.

💜 Hinglish samjho

Input layer = data andar aata hai. Hidden layer = "sochne waala dimaag", ReLU lagake complex pattern pakadta hai. Output layer = ek neuron + sigmoid jo 0 se 1 ke beech probability deta hai. 0.5 se upar = Yes, neeche = No. Loss = binary cross-entropy, training = backprop.

🟢 Easy example (English)

Spam filter: inputs = number of links and number of words like "FREE". The hidden layer learns combos like "many links AND many FREE words". The output gives P(spam) = 0.92, so the mail is spam.

🌸 आसान उदाहरण (हिंदी)

छात्र पास होगा या फेल? इनपुट: पढ़ाई के घंटे और उपस्थिति। हिडन लेयर इनका मेल समझती है ("घंटे कम पर उपस्थिति ज़्यादा")। आउटपुट: पास होने की संभावना 0.8, यानी पास।

💡 Exam tip

"Design" questions want a table (layer, neurons, activation) + loss + optimiser + diagram. Always justify: sigmoid at output because the answer is a probability for two classes.

Q5 ⭐ HIGH★★★★☆ 2 / 4 / 10 marks
What is Maximum Likelihood Estimation (MLE)? How is it used in deep learning?
📝 Exam answer

MLE is a method of estimating the parameters θ of a model by choosing the values that make the observed data most probable.

Likelihood: L(θ) = Πᵢ p(xᵢ ; θ)
θML = argmaxθ Πᵢ p(xᵢ ; θ) = argmaxθ Σᵢ log p(xᵢ ; θ)

We take the log because a product of many small probabilities underflows; the log turns it into a sum and doesn't change the argmax.

Worked example (coin)

Toss a coin 10 times: 7 Heads, 3 Tails. Find p = P(Head).
L(p)      = p^7 (1 − p)^3
log L(p)  = 7 log p + 3 log(1 − p)
d/dp = 7/p − 3/(1 − p) = 0   →   7(1 − p) = 3p   →   p = 7/10 = 0.7

Link to deep learning

  • Training a network = MLE. We minimise the negative log-likelihood (NLL).
  • For classification (softmax/sigmoid output), NLL = cross-entropy loss.
  • For regression with Gaussian noise, NLL = Mean Squared Error.
  • Properties: consistent (with more data it approaches the true θ) and efficient; but it can overfit on small data (so we add regularisation, i.e. MAP).
💜 Hinglish samjho

Data dekh ke ulta sochna: "kaunsa parameter hota toh yeh data aane ka chance sabse zyada hota?" 10 mein 7 heads aaye, toh sabse believable p = 0.7. Deep learning mein cross-entropy loss minimise karna = asal mein MLE karna hai.

🟢 Easy example (English)

You see 8 out of 10 people on a street carrying umbrellas. The most likely explanation is "it is going to rain" (high rain probability). You pick the explanation that best fits what you observed.

🌸 आसान उदाहरण (हिंदी)

सड़क पर 10 में से 8 लोग छाता लेकर चल रहे हैं। सबसे संभावित कारण — "बारिश होने वाली है"। जो कारण देखे गए डेटा को सबसे अच्छी तरह समझाए, उसे चुनना ही MLE है।

💡 Exam tip

Write the formula + coin derivation + "cross-entropy = NLL". That's a complete 4–5 mark answer.

Q6 ⭐ HIGH★★☆☆☆ 2 / 4 marks7CAI 2025 A8
What are Deep Feed-forward Networks? Why do we need hidden layers? (XOR problem)
📝 Exam answer

A deep feed-forward network (DFN / MLP) approximates a function y = f*(x). Information flows only forward from input → hidden layers → output, with no feedback loops (unlike RNNs). It is a chain of functions:

f(x) = f⁽³⁾( f⁽²⁾( f⁽¹⁾(x) ) ) — number of layers in the chain = depth
  • Hidden layers: their outputs are not seen in the training data, so the network decides what they compute.
  • Non-linear activation (ReLU) is necessary. Without it, many layers collapse into one linear layer.
  • Universal Approximation Theorem: one hidden layer with enough neurons can approximate any continuous function; deeper networks do it with far fewer neurons.

XOR example

x₁x₂XOR
000
011
101
110

No single straight line separates the 1s from the 0s, so a single perceptron fails. One hidden layer with 2 ReLU units maps the points to a new space where they become linearly separable. This shows why depth / hidden layers are needed.

💜 Hinglish samjho

Data seedha aage badhta hai, koi loop nahi. Hidden layers = beech ke "kaarigar" jo raw data ko naye form mein badalte hain. XOR ek line se nahi kat-ta, hidden layer usko aisa modta hai ki kat jaaye.

🟢 Easy example (English)

A factory assembly line: raw metal → cut → shaped → painted → car. Each station (layer) does one job and passes it forward, never backward.

🌸 आसान उदाहरण (हिंदी)

रोटी बनाना: आटा → गूँधना → बेलना → सेकना → रोटी। हर स्टेप आगे ही जाता है, पीछे नहीं। यही feed-forward है।

Q7 ⭐ HIGH★★☆☆☆ 2 / 4 marks
Explain the Perceptron and its learning rule. What is its limitation?
📝 Exam answer

The perceptron (Rosenblatt, 1958) is the simplest neural unit. It takes inputs x, multiplies them by weights, adds a bias and passes the result through a step function:

y = step(Σ wᵢxᵢ + b), step(z) = 1 if z ≥ 0 else 0

Learning rule: wᵢ ← wᵢ + η (t − y) xᵢ, b ← b + η (t − y). Weights change only when the prediction is wrong.

Perceptron convergence theorem: if the data is linearly separable, the rule finds a separating line in finite steps.

Limitation: it can only solve linearly separable problems (AND, OR) and not XOR (Minsky & Papert, 1969). Solution: the multilayer perceptron.

💜 Hinglish samjho

Perceptron = ek chhota decision-maker. Sab inputs ko importance (weight) se multiply karo, jodo, threshold paar hua toh 1 warna 0. Galat hua toh weight thoda badlo. Sirf seedhi line se alag hone waale problem solve karta hai.

🟢 Easy example (English)

Should I go out? Inputs: sunny (weight 0.6), friend coming (0.5), exam tomorrow (−0.9). If the weighted sum is above 0, go out.

🌸 आसान उदाहरण (हिंदी)

बाहर घूमने जाऊँ? धूप है (+), दोस्त आ रहा है (+), कल परीक्षा है (−)। सबको उनके महत्व से गुणा करके जोड़ो; कुल योग 0 से ज़्यादा हुआ तो जाओ।

Q8 ✔ MEDIUM★★☆☆☆ 4 marks
Explain the steps / components of building a machine learning algorithm.
📝 Exam answer

Almost every ML/DL algorithm is a recipe of four components (Goodfellow, Deep Learning book):

  1. Dataset: the examples (X, y) we learn from.
  2. Model: a family of functions, e.g. linear model or neural network y = f(x; θ).
  3. Cost / loss function: measures error, e.g. MSE, cross-entropy (NLL), plus regularisation.
  4. Optimisation procedure: finds θ that minimises the cost, e.g. gradient descent / SGD.

Practical pipeline (6 steps): Problem definition → Data collection & preprocessing → Model selection → Training → Evaluation (validation/test) → Deployment & monitoring.

💜 Hinglish samjho

Recipe ki tarah: ingredients = data, bartan = model, taste check = loss, aanch adjust karna = optimiser. Charon change karke alag-alag algorithm ban jaate hain.

🟢 Easy example (English)

House-price predictor: data = old sale records; model = linear regression; loss = MSE; optimiser = gradient descent.

🌸 आसान उदाहरण (हिंदी)

खाना बनाना: सामग्री = डेटा, बर्तन = मॉडल, स्वाद चखना = लॉस, आँच कम-ज़्यादा करना = ऑप्टिमाइज़र।

Q9 ✔ MEDIUM★☆☆☆☆ 2 marks
What is a learning algorithm? (Task, Performance, Experience)
📝 Exam answer

Tom Mitchell's definition: "A computer program is said to learn from experience E with respect to some task T and performance measure P, if its performance at T, as measured by P, improves with experience E."

Example: Spam filter. T = classify emails, P = % correctly classified, E = labelled emails.

Types: Supervised (labelled data), Unsupervised (no labels), Reinforcement (rewards). Common DL learning algorithms: FNN, CNN, RNN/LSTM, Autoencoders, GANs, Transformers.

💜 Hinglish samjho

Jo program practice (E) se kisi kaam (T) mein behtar (P) hota jaaye, woh "seekh raha hai".

🟢 Easy example (English)

A child learning to ride a cycle: T = ride, P = distance without falling, E = practice days.

🌸 आसान उदाहरण (हिंदी)

बच्चा साइकिल चलाना सीखता है: काम = चलाना, माप = बिना गिरे कितनी दूरी, अनुभव = रोज़ का अभ्यास।

⚡ Part-A quick answers (2 marks, ~25 words each)

  1. Curse of dimensionality? As the number of features grows, the space grows exponentially, the data becomes sparse, distances lose meaning and models overfit and need exponentially more data. 2025 2024
  2. Backpropagation? An algorithm that computes the gradient of the loss w.r.t. each weight using the chain rule, from output to input, and updates the weights via gradient descent. 2025 2024
  3. SGD? Gradient descent that updates the weights using one random training sample at a time: w ← w − η∇Lᵢ. It is fast and noisy. 2025
  4. Learning rate? A hyper-parameter η that controls the step size of weight updates. Too high: diverges. Too low: very slow.
  5. Epoch vs batch vs iteration? Epoch = one full pass over the data; batch = subset used per update; iteration = one update step.
  6. MLE? Choose the parameters θ that maximise the probability of the observed data: θ = argmax Σ log p(xᵢ;θ).
  7. MLP? A feed-forward network with input, ≥1 hidden layer with non-linear activation, and an output layer, trained with backpropagation. 7CAI
  8. Why is a non-linear activation needed? Without it, stacked layers collapse into one linear function, so the network can't learn non-linear patterns like XOR.
  9. Vanishing gradient? Gradients become tiny as they flow back through many sigmoid/tanh layers, so early layers stop learning. Fix: ReLU, batch-norm, ResNet.
  10. Momentum? Adds a fraction of the previous update to the current one (v = βv + η∇L). This speeds up training and reduces oscillation.
  11. Overfitting vs underfitting? Overfitting: good on training data, bad on test data (memorises). Underfitting: bad on both (too simple).
  12. Deep feed-forward network? A network where information flows only forward (input → hidden layers → output) with no feedback loops, approximating y = f*(x). 7CAI
  13. Universal approximation theorem? A feed-forward net with one hidden layer and enough neurons can approximate any continuous function.
