Q1 🔥 MUST DO★★★☆☆ 4 / 10 marksPYQ 2025 B5
Explain the architecture and working of a Recurrent Neural Network. Given a sequence prediction problem, propose how you would implement an RNN to solve it.
📝 Exam answer

Definition: A Recurrent Neural Network (RNN) is a neural network for sequential data (text, speech, time series). It has a loop: the hidden state from the previous time step is fed back with the current input, so the network keeps a memory of the past. The same weights are shared across all time steps.

hₜ = tanh( Whh hₜ₋₁ + Wxh xₜ + bh )
yₜ = Why hₜ + by (softmax on yₜ for classification)
  • xₜ = input at time t, hₜ = hidden state (memory), yₜ = output.
  • Unfolding: the loop is drawn as a chain of copies, one per time step (see diagram).
  • Training: Backpropagation Through Time (BPTT).

Types of RNN (by input/output shape)

TypeExample
One-to-oneNormal classification (no sequence)
One-to-manyImage captioning (one image → sentence)
Many-to-oneSentiment analysis (sentence → positive/negative)
Many-to-many (same length)POS tagging / NER (a tag for each word)
Many-to-many (different length)Machine translation (encoder–decoder)

Implementation for a sequence prediction problem (e.g. predict tomorrow's temperature from the last 7 days)

  1. Data preparation: collect the daily temperature series; normalise (min-max); make sliding windows: input = days 1–7 → target = day 8, then days 2–8 → day 9, and so on. Split train / validation / test in time order (no shuffling across time).
  2. Model: input shape (7 time steps × 1 feature) → RNN/LSTM layer (e.g. 32 units, tanh) → Dense(1) linear output. (Many-to-one.)
  3. Loss & optimiser: MSE loss (regression), Adam optimiser, learning rate 0.001.
  4. Training: BPTT over the 7 steps, mini-batches, 50 epochs, early stopping on validation loss; gradient clipping to avoid exploding gradients.
  5. Evaluation: RMSE / MAE on the test set; plot predicted vs actual.
  6. Prediction: feed the latest 7 days and get the next day; for multiple days, feed predictions back in (recursive forecasting).

For next-word prediction the same plan applies with: words → embeddings, output = softmax over the vocabulary, loss = cross-entropy.

🧮 Tiny numerical: computing hidden states

Given (scalar RNN): Wxh = 0.5, Whh = 0.8, b = 0, Why = 1.2, h₀ = 0, input sequence x = [1, 2].

t = 1:  h1 = tanh(0.8·0 + 0.5·1)       = tanh(0.5)    = 0.4621
t = 2:  h2 = tanh(0.8·0.4621 + 0.5·2)  = tanh(1.3697) = 0.8786
Output: y2 = 1.2 × 0.8786 = 1.0543

Note: h2 depends on x1 through h1 → this is the "memory".
💜 Hinglish samjho

Normal neural network ki memory nahi hoti, har input alag dekhta hai. RNN har step pe apna "notes" (hidden state hₜ) agle step ko pass karta hai. Isliye sentence ka matlab ya kal ka temperature samajh paata hai. Weights sab steps pe same hote hain. Implement karne ke liye: data ko 7-7 din ki window mein kaato → RNN layer → Dense output → MSE loss → BPTT se train → predict.

🟢 Easy example (English)

Reading a story: you understand the word "he" only because you remember who was mentioned earlier. An RNN reads word by word and carries that memory forward, just like you.

🌸 आसान उदाहरण (हिंदी)

फ़िल्म देखते समय आप पिछले सीन याद रखते हैं, तभी अगला सीन समझ आता है। RNN भी हर कदम पर पिछली जानकारी (hidden state) को याद रखकर आगे बढ़ता है।

Q2 🔥 MUST DO★★★★☆ 4 / 10 marks7CAI 2025 C42025 C4 (LSTM)
Explain the LSTM architecture with its gates. How does it solve the vanishing gradient problem? Compare RNN, LSTM and GRU in terms of structure, training efficiency and applications.
📝 Exam answer

LSTM (Long Short-Term Memory), by Hochreiter & Schmidhuber (1997), is a special RNN that can learn long-term dependencies. Besides the hidden state hₜ, it keeps a cell state Cₜ (a "conveyor belt" of memory). Three gates (sigmoid, output 0–1) control what to forget, what to add and what to output.

Forget gate: fₜ = σ(Wf[hₜ₋₁, xₜ] + bf)
Input gate: iₜ = σ(Wi[hₜ₋₁, xₜ] + bi)
Candidate: C̃ₜ = tanh(WC[hₜ₋₁, xₜ] + bC)
Cell update: Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ C̃ₜ
Output gate: oₜ = σ(Wo[hₜ₋₁, xₜ] + bo)
Hidden state: hₜ = oₜ ⊙ tanh(Cₜ)
  • Forget gate: decides what old memory to erase (0 = forget fully, 1 = keep fully).
  • Input gate: decides what new information to write.
  • Output gate: decides what part of the memory to show as hₜ.

Why it solves vanishing gradients

In a plain RNN the gradient is multiplied by Whh·tanh′ at every step, so it shrinks exponentially. In an LSTM the cell state is updated by addition (Cₜ = fₜCₜ₋₁ + …). The gradient along the cell path is ∂Cₜ/∂Cₜ₋₁ = fₜ, and when the forget gate ≈ 1 the gradient flows almost unchanged through many steps (the "constant error carousel").

RNN vs LSTM vs GRU

PointSimple RNNLSTMGRU
Structure1 tanh layer, hidden state only3 gates (forget, input, output) + cell state2 gates (update, reset), no separate cell state
Parameters (per unit)Fewest (1 weight set)Most (4 weight sets)Medium (3 weight sets)
Long-term memoryPoor (vanishing gradient)ExcellentVery good
Training efficiencyFast per step but unstableSlowest, more memory~25% faster than LSTM, similar accuracy
Best forShort sequences, simple tasksLong sequences: speech, translation, long textSmaller datasets, real-time / mobile
ApplicationsSimple time series, char predictionSpeech recognition, machine translation, handwritingChatbots, sentiment, music generation

GRU equations (brief): zₜ = σ(Wz[hₜ₋₁,xₜ]), rₜ = σ(Wr[hₜ₋₁,xₜ]), h̃ₜ = tanh(W[rₜ⊙hₜ₋₁, xₜ]), hₜ = (1 − zₜ)⊙hₜ₋₁ + zₜ⊙h̃ₜ.

💜 Hinglish samjho

Simple RNN ki memory "goldfish" jaisi hai, purani baatein jaldi bhool jaata hai. LSTM ke paas ek alag diary hai (cell state) aur 3 darwaaze (gates): forget gate = purani faltu baat mitao, input gate = nayi zaroori baat likho, output gate = abhi kya bolna hai. Diary mein update "jodkar" (addition) hota hai, isliye gradient gaayab nahi hota. GRU = LSTM ka halka version, 2 gates, fast.

🟢 Easy example (English)

"I grew up in France … (50 words later) … so I speak fluent ___." A simple RNN has forgotten "France" by then. An LSTM kept "France" in its cell state (forget gate ≈ 1), so it predicts "French".

🌸 आसान उदाहरण (हिंदी)

एक छात्र की नोटबुक: पुराने बेकार नोट्स मिटाता है (forget gate), नए ज़रूरी पॉइंट लिखता है (input gate), और परीक्षा में सिर्फ़ ज़रूरी हिस्सा लिखता है (output gate)। इसलिए लंबे समय तक ज़रूरी बातें याद रहती हैं।

Q3 🔥 MUST DO★★☆☆☆ 2 / 4 marksPYQ 2025 A8PYQ 2024 A9
Define Bidirectional Recurrent Neural Networks (BRNNs). Explain their working.
📝 Exam answer

Definition: A Bidirectional RNN (Schuster & Paliwal, 1997) uses two RNN layers on the same input: one reads the sequence forward (past → future) and the other reads it backward (future → past). Their hidden states are concatenated, so each output uses both past and future context.

Forward: →hₜ = f(Wf xₜ + Vf →hₜ₋₁ + bf)
Backward: ←hₜ = f(Wb xₜ + Vb ←hₜ₊₁ + bb)
Output: yₜ = g( U [→hₜ ; ←hₜ] + c )
  • The two directions have separate weights; both are trained together with BPTT.
  • Applications: Named Entity Recognition, POS tagging, speech recognition, machine translation encoders, handwriting recognition, BERT-style context understanding.
  • Limitations: the whole sequence must be available before processing, so it is not usable for real-time / streaming prediction (e.g. live next-word typing); it needs about 2× the computation.
💜 Hinglish samjho

Ek RNN sentence ko aage se padhta hai, doosra peeche se. Dono ke notes jod do, toh har word ko poora context milta hai, pehle ka bhi aur baad ka bhi. Problem: poora sentence pehle chahiye, isliye live typing prediction mein kaam nahi aata.

🟢 Easy example (English)

"He said, Teddy bears are on sale." vs "He said, Teddy Roosevelt was a president." From the left side alone you can't tell if "Teddy" is a person. The words to the right decide it. A BRNN sees both sides.

🌸 आसान उदाहरण (हिंदी)

"मैंने आम खाया" और "यह एक आम बात है" — "आम" का अर्थ बाद वाले शब्दों से तय होता है। BRNN वाक्य को आगे और पीछे दोनों तरफ़ से पढ़ता है, इसलिए सही अर्थ समझ लेता है।

💡 Exam tip

2-mark answer: "A BRNN has two RNNs, one processing the sequence forward and one backward; their hidden states are concatenated so each output uses past and future context. Used in NER and speech recognition."

Q4 🔥 MUST DO★★★☆☆ 2 / 4 / 10 marks7CAI 2025 A57CAI 2025 B4
Describe the Encoder–Decoder sequence-to-sequence architecture with a neat diagram.
📝 Exam answer

Definition: The encoder–decoder (seq2seq) model (Sutskever et al. 2014, Cho et al. 2014) maps an input sequence to an output sequence of a different length, e.g. English sentence → Hindi sentence. It has two RNNs (usually LSTM/GRU):

  1. Encoder: reads the input x₁…xT one token at a time and updates its hidden state. Its final hidden state is the context vector C, a fixed-length summary of the whole input.
  2. Context vector: C = hT (encoder's last state) is used as the initial state of the decoder.
  3. Decoder: starting from the <START> token, it generates the output y₁…yT′ one token at a time. Each step uses the previous output word, its own hidden state and C. It stops at <END>.
Encoder: hₜ = f(xₜ, hₜ₋₁), C = hT
Decoder: sₜ = g(yₜ₋₁, sₜ₋₁, C), P(yₜ) = softmax(W sₜ)
  • Training: maximise log P(y | x) (cross-entropy) using teacher forcing: during training the decoder is fed the true previous word, not its own guess.
  • Inference: greedy decoding or beam search.
  • Bottleneck problem: one fixed-size C must hold the whole sentence, so quality drops for long sentences.
  • Attention (fix): the decoder looks at all encoder states at each step and takes a weighted sum (context cₜ = Σ αₜᵢ hᵢ). This led to Transformers.
  • Applications: machine translation, text summarisation, chatbots, speech-to-text, image captioning (CNN encoder + RNN decoder).
💜 Hinglish samjho

Encoder = sunne waala: poora English sentence sunke uska "saar" ek vector (C) mein yaad rakhta hai. Decoder = bolne waala: us saar se Hindi mein ek-ek shabd bolta hai jab tak <END> na aa jaaye. Lamba sentence ho toh ek chhote vector mein sab yaad nahi rehta (bottleneck), isliye attention aaya, jo har step pe poore input pe nazar daalta hai.

🟢 Easy example (English)

A human interpreter listens to a full English sentence, holds its meaning in mind (context vector), and then speaks it in Hindi word by word. Input and output lengths can differ.

🌸 आसान उदाहरण (हिंदी)

दुभाषिया (translator) पहले पूरा अंग्रेज़ी वाक्य सुनता है, उसका मतलब मन में रखता है (context vector), फिर हिंदी में एक-एक शब्द बोलता है। यही एनकोडर–डिकोडर है।

💡 Exam tip

"Neat diagram" = boxes for the encoder and decoder, a clearly labelled context vector C in between, and a real translation example. Mention teacher forcing, the bottleneck and attention for extra marks.

Q5 🔥 MUST DO★★★★☆ 10 marksPYQ 2025 C4
Propose a deep learning pipeline for speech recognition, detailing each step from pre-processing to LSTM model evaluation.
📝 Exam answer

Goal: Automatic Speech Recognition (ASR) converts an audio waveform into text. The pipeline below uses an LSTM-based acoustic model.

  1. Data collection: recorded audio clips with transcripts, e.g. LibriSpeech or Common Voice. Use different speakers, accents and noise conditions. Split into train / validation / test by speaker.
  2. Pre-processing:
    • Convert to mono and resample to 16 kHz; normalise amplitude.
    • Noise reduction / silence trimming (Voice Activity Detection).
    • Pre-emphasis filter to boost high frequencies.
    • Framing: split into short frames of ~25 ms with a 10 ms hop (overlap), because speech is roughly stationary over short periods.
    • Windowing: multiply each frame by a Hamming window to reduce edge effects.
  3. Feature extraction: FFT → Mel filter bank → log → DCT gives MFCCs (13 coefficients + Δ + ΔΔ = 39 features per frame), or a log-Mel spectrogram (80 bins). Apply per-speaker mean/variance normalisation. Optional augmentation: SpecAugment, speed change, added noise.
  4. Label preparation: normalise the transcripts (lower-case, remove punctuation) and tokenise into characters or sub-words. Add a blank token for CTC.
  5. Model architecture: input (T frames × 39) → optional CNN layers (local patterns, downsampling) → 2–5 stacked Bidirectional LSTM layers (256–512 units, dropout 0.2–0.3) → Dense + softmax over the characters at every frame.
  6. Loss: CTC (Connectionist Temporal Classification) loss, which aligns long audio frame sequences with shorter text without frame-level labels. (Alternative: an attention-based encoder–decoder with cross-entropy.)
  7. Training: Adam optimiser (lr ≈ 1e-3 with decay), mini-batches sorted by length, BPTT, gradient clipping, dropout, early stopping on validation loss/WER.
  8. Decoding: greedy decoding (take the best character per frame, merge repeats, remove blanks), or beam search with a language model (n-gram / neural LM) for better sentences.
  9. Evaluation: Word Error Rate on the test set (also CER = character error rate, and real-time factor for speed).
    WER = (S + D + I) / N (S = substitutions, D = deletions, I = insertions, N = words in the reference)
    Reference : the cat sat on the mat          (N = 6)
Predicted : the cat sit on mat today
S = 1 (sat→sit), D = 1 (the), I = 1 (today)
WER = (1 + 1 + 1) / 6 = 0.50 = 50%    → lower is better
  10. Deployment: export the model (TensorFlow Lite / ONNX), quantise it for mobile, run streaming inference (use a unidirectional LSTM for real-time), and monitor errors.
💜 Hinglish samjho

Awaaz → saaf karo (16 kHz, noise hatao) → 25 ms ke chhote tukde (frames) → har tukde ka "fingerprint" nikaalo (MFCC) → BiLSTM har frame ke liye bataata hai kaunsa akshar hai → CTC loss se train (alignment ki tension nahi) → beam search + language model se sahi sentence banao → WER se check karo kitni galti hui (kam WER = achha model).

🟢 Easy example (English)

Google voice typing: you say "call mom". The phone cleans the audio, turns it into MFCC frames, the LSTM predicts letters "c-a-l-l m-o-m", and the language model makes sure it writes "call mom" and not "coal mom".

🌸 आसान उदाहरण (हिंदी)

आप फ़ोन में बोलते हैं "मम्मी को कॉल करो"। फ़ोन आवाज़ साफ़ करता है, छोटे-छोटे टुकड़ों में बाँटता है, हर टुकड़े की पहचान (MFCC) निकालता है, LSTM अक्षर पहचानता है, और भाषा-मॉडल सही वाक्य बनाता है। गलतियाँ गिनकर WER निकाला जाता है।

Q6 ⭐ HIGH★★★★☆ 4 / 10 marks
Explain Backpropagation Through Time (BPTT) for training RNNs. What are vanishing and exploding gradients and how are they handled?
📝 Exam answer

BPTT is backpropagation applied to the unfolded RNN. Steps:

  1. Unfold the RNN for T time steps (one copy per step, all sharing Wxh, Whh, Why).
  2. Forward pass through all steps; compute the loss at each step; total loss L = Σₜ Lₜ.
  3. Backward pass from t = T back to t = 1, applying the chain rule through time.
  4. Because the weights are shared, add up the gradients from all time steps: ∂L/∂W = Σₜ ∂Lₜ/∂W.
  5. Update the weights with gradient descent.
∂Lₜ/∂Whh = Σk=1..t (∂Lₜ/∂hₜ) · ( Πj=k+1..t ∂hⱼ/∂hⱼ₋₁ ) · (∂hₖ/∂Whh), ∂hⱼ/∂hⱼ₋₁ = Whhᵀ · diag(tanh′)

Vanishing / exploding gradients

  • The product Π ∂hⱼ/∂hⱼ₋₁ multiplies Whh many times. If its values are < 1, the gradient → 0 (vanishing): the RNN can't learn long-term dependencies. If > 1, the gradient → ∞ (exploding): the weights become NaN.
  • Fixes for exploding: gradient clipping (if ‖g‖ > threshold, rescale g = threshold · g/‖g‖), smaller learning rate.
  • Fixes for vanishing: LSTM / GRU gates, ReLU, good initialisation (identity/orthogonal Whh), skip connections, attention.

Truncated BPTT: backpropagate only k steps (e.g. 20–50) instead of the full sequence. This saves memory and time for long sequences, but dependencies longer than k are harder to learn.

💜 Hinglish samjho

RNN ko time mein khol do (unfold), phir normal backprop karo, aakhri step se pehle step tak. Weights sab steps pe same hain, isliye sab steps ke gradients ko jod do. Problem: gradient baar-baar multiply hota hai, <1 hua toh gaayab (vanishing), >1 hua toh fat jaata hai (exploding). Exploding ka ilaaj = clipping, vanishing ka ilaaj = LSTM/GRU.

🟢 Easy example (English)

Chinese whispers: a message passed through 20 people gets weaker and weaker until it is lost (vanishing). If everyone exaggerates it, it becomes wildly distorted (exploding).

🌸 आसान उदाहरण (हिंदी)

0.5 को 20 बार गुणा करो → लगभग 0 (vanishing)। 1.5 को 20 बार गुणा करो → लगभग 3325 (exploding)। RNN में ग्रेडिएंट के साथ यही होता है।

💡 Exam tip

The numbers 0.5²⁰ ≈ 0.000001 and 1.5²⁰ ≈ 3325 make the vanishing/exploding point instantly clear in any answer.

Q7 ⭐ HIGH★★☆☆☆ 2 / 4 / 10 marks7CAI 2025 A6, B6
Explain applications of deep sequence models in computer vision, speech recognition and NLP, with case studies in classification and regression. What are recursive neural networks?
📝 Exam answer

Computer vision

  • Image captioning: CNN encoder (image features) + LSTM decoder ("A dog is running on grass").
  • Video classification / action recognition: CNN per frame + LSTM over frames.
  • Handwriting / OCR: CNN + BiLSTM + CTC reads text lines.

Speech recognition

  • BiLSTM + CTC or seq2seq acoustic models (Google voice, Alexa, Siri). Also speech synthesis and speaker identification. (See Q5.)

Natural Language Processing

  • Machine translation (seq2seq), sentiment analysis, next-word prediction / autocomplete, named entity recognition, chatbots, text summarisation.

Case study 1: Classification (sentiment analysis of movie reviews, IMDB)

  1. Tokenise reviews, pad to 200 words, word embeddings (100-d).
  2. LSTM(64) → Dense(1, sigmoid). Many-to-one.
  3. Binary cross-entropy loss, Adam. Accuracy ≈ 85–88%.
  4. "The movie was not good at all" → negative. The LSTM catches "not … good", which bag-of-words misses.

Case study 2: Regression (electricity load / stock / temperature forecasting)

  1. Sliding window of the last 24 hours → predict the next hour.
  2. LSTM(50) → Dense(1, linear). MSE loss.
  3. Evaluate with RMSE / MAE; it beats ARIMA on non-linear patterns.

Recursive neural networks

A recursive neural network applies the same weights over a tree structure (e.g. the parse tree of a sentence) instead of a linear chain. Child node vectors are combined into the parent: p = tanh(W[c₁; c₂] + b). Used for sentiment of phrases (Stanford Sentiment Treebank) and parsing. An RNN (recurrent) is a special case where the tree is a chain. Recursive nets need a parse tree, and depth is O(log n) for balanced trees.

💜 Hinglish samjho

Jahaan bhi data "line mein" aata hai, wahaan RNN/LSTM: photo ka caption, video, awaaz se text, translation, review positive/negative (classification), kal ka temperature/share price (regression). Recursive net = same idea par chain ki jagah tree pe chalta hai (sentence ka grammar tree).

🟢 Easy example (English)

Instagram's auto alt-text describes your photo ("two people smiling outdoors"). A CNN looks at the photo and an LSTM writes the sentence.

🌸 आसान उदाहरण (हिंदी)

अमेज़न पर रिव्यू "प्रोडक्ट बिल्कुल अच्छा नहीं है" — LSTM "नहीं" और "अच्छा" दोनों को साथ समझकर इसे नकारात्मक (negative) बताता है। यह classification है; कल का तापमान बताना regression है।

⚡ Part-A quick answers (2 marks, ~25 words each)

  1. Bidirectional RNN? Two RNNs process the sequence forward and backward; their hidden states are concatenated so each output uses past and future context. Used in NER and speech. 2025 2024
  2. Encoder–decoder model in seq2seq? The encoder RNN compresses the input sequence into a context vector; the decoder RNN generates the output sequence from it, e.g. machine translation. 7CAI 2025
  3. RNN? A neural network with recurrent connections; the hidden state hₜ = tanh(Whhhₜ₋₁ + Wxhxₜ) carries memory of past inputs. Used for sequences.
  4. LSTM? An RNN with a cell state and forget, input and output gates that control memory, so it learns long-term dependencies and avoids vanishing gradients.
  5. GRU? A simpler LSTM with only update and reset gates and no separate cell state. Faster, with similar accuracy.
  6. BPTT? Backpropagation applied to an RNN unfolded in time; gradients from all time steps are summed because the weights are shared.
  7. Truncated BPTT? Backpropagating only a fixed number k of recent time steps, to save memory and computation on long sequences.
  8. Gradient clipping? Rescaling gradients when their norm exceeds a threshold, to prevent exploding gradients in RNN training.
  9. Vanishing gradient in RNN? Repeated multiplication by small derivatives through time makes the gradients ≈ 0, so early inputs can't influence learning.
  10. Teacher forcing? During decoder training, the true previous token is fed as input instead of the model's own prediction, which speeds up convergence.
  11. Attention mechanism? The decoder computes a weighted sum of all encoder hidden states at each step, focusing on the relevant input words. It removes the fixed-context bottleneck.
  12. CTC loss? Connectionist Temporal Classification aligns long input frame sequences with shorter label sequences using a blank token, without frame-level alignment. Used in ASR.
  13. WER? Word Error Rate = (S + D + I)/N. The standard evaluation metric for speech recognition; lower is better.
  14. Recursive vs recurrent? Recurrent nets share weights along a time chain; recursive nets share weights over a tree structure (e.g. a parse tree).
  15. One major use of DL in computer vision? Image classification / object detection with CNNs, e.g. face recognition or detecting tumours in medical scans. 7CAI 2025
